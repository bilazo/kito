> Use a switch for a setting applied right away (notifications, dark mode).
> For a choice the user confirms with a Save button, use `Checkbox` — a switch
> implies "already applied".

## RTL

The thumb is positioned with `inset-inline-start` (a logical CSS property),
so it sits on the reading-start side when off and slides to the
reading-end side when on — automatically, with no `dir`-specific code. In
an RTL page, "start" is the right side, so the thumb starts at the right
and moves left when toggled. The visible track itself is symmetric and
looks identical in both directions.
