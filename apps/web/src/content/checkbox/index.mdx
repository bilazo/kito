## Basic

Pair `Checkbox` with `Label` via `htmlFor` and `id`. Clicking the label toggles
the checkbox and screen readers announce them as one control.

## States

Base UI drives all states via `data-*` attributes — the styling stays in sync
even when the value is controlled from outside React.

## Group with "select all"

## Inside a Field

For a row of checkboxes with a label and description, use
`Field orientation="horizontal"`. Base UI wires the label to the control
automatically — no `htmlFor` needed.

## RTL

The checkbox itself is symmetric, so it looks identical in LTR and RTL.
Only the surrounding flex layout flips: a label placed after the box in JSX
appears on the reading-start side (right) in an RTL page. The extended
click area (`after:-inset-x-3`) is symmetric, so the 44×44 touch target
holds in both directions.
