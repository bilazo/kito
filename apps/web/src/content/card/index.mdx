Compose a card from `CardHeader`, `CardTitle`, `CardDescription`,
`CardAction`, `CardContent`, and `CardFooter`. Only the parts you need are
required.

The card's internal padding and gap are driven by a single CSS variable,
`--card-spacing`, set by `size`. Override it per card with an arbitrary
property class — `[--card-spacing:--spacing(2)]` — for edge-to-edge content
or a tighter list.

## Interactive with a stretched link

Pass `interactive` when the card contains a stretched link. The whole card
reacts to hover and focus, signaling that the surface itself is clickable.

The pattern: put a real `<a>` in the title and give it
`after:absolute after:inset-0`. The link expands to cover the card, and the
card's `:has(a:hover)` state provides the affordance.

## Stat

`CardTitle` renders as `<h3>` by default so screen readers announce the card
as a titled section. For non-heading titles — a numeric value, a badge — pass
`render={<div />}`.
