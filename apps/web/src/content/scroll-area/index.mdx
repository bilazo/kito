Native scrolling — `overflow: auto`, momentum on touch, keyboard scrolling
— works as usual. ScrollArea adds a **styleable** scrollbar that does not
depend on the OS-chrome look of `::-webkit-scrollbar`.

## Basic

Give the root a size (`h-…`, `w-…`, or both). The viewport fills it.

<ComponentPreview name="scroll-area/basic" />

## Horizontal

`ScrollArea` renders one vertical scrollbar by default. Add a second one
for horizontal scrolling:

```tsx
<ScrollArea className="w-80">
  {wideContent}
  <ScrollBar orientation="horizontal" />
</ScrollArea>
```

<ComponentPreview name="scroll-area/horizontal" />

## Both axes

Add a horizontal `ScrollBar` alongside the default vertical one for

## RTL

Base UI flips the scroll axis in RTL automatically. The vertical scrollbar
moves to the inline-end (left in RTL) and horizontal scrolling starts from
the reading start.
