Most apps set `<html dir="rtl">` once and never think about direction again —
every component picks it up from the DOM. `DirectionProvider` is for
**scoping** RTL to a portion of the page: a preview pane, an embedded widget
in an RTL host, a docs site that demonstrates both directions side by side,
or any Base UI popup that portals to `<body>` and would otherwise escape the
surrounding container's `dir`.

## Scoped direction

Wrap only the part that should flip. Everything outside keeps the page's
default direction.

Pair with `dir="rtl"` on a DOM wrapper so CSS logical properties flip
alongside the React context.

## useDirection

`useDirection` reads the current direction from the nearest provider (or
the closest `dir` attribute) — useful when a component needs to branch on
direction for behavior, not just for CSS.
