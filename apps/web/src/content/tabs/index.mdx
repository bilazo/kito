`Tabs` renders no DOM of its own. Compose it from `TabsList`, `TabsTab`,
`TabsIndicator` (optional), and `TabsPanel`.

## Line variant

The `line` variant replaces the pill background with an underline that slides
beneath the active tab. Use it for navigation-style tabs where the tab strip
should blend into the page.

Pass `variant="line"` to **both** `TabsList` and each `TabsTab` — they share
the styling through group modifiers, but each needs its own class.

## Vertical

Set `orientation="vertical"` on the root, the list, and each tab. Panels sit

## RTL

The tab strip uses logical layout (`justify-start` on vertical tabs, `gap`
without direction-specific values), so the tabs and their panels flip with
the page direction. The `TabsIndicator` positions itself using CSS variables
that Base UI measures physically (`--active-tab-left`, `--active-tab-width`)
— those measurements are relative to the list's left edge, so the pill
follows the active tab in both directions without a `dir`-specific class.

A `TabsIndicator` that needs to place itself on the vertical line variant’s
trailing edge uses a physical `right` utility — worth verifying in an RTL
page before shipping, as that position does not flip with `dir`.
