The number of thumbs is derived from `value` / `defaultValue`:

```tsx
<Slider defaultValue={33} />          // one thumb
<Slider defaultValue={[25, 75]} />    // two thumbs — a range
<Slider defaultValue={[10, 50, 90]} /> // three thumbs
```

## Range

An array value gives a two-thumb range slider. The lower thumb cannot be
dragged past the upper one — Base UI clamps the movement.

## Controlled

Pass `value` and `onValueChange` to drive the state from outside. The value
is always an array, even for a single-thumb slider.

## RTL

Base UI flips the axis automatically when `dir="rtl"` is set on the slider
or an ancestor. The track fills from the reading start (right in RTL).

<ComponentPreview name="slider/rtl" />

## Keyboard

| Key                       | Action                |
| ------------------------- | --------------------- |
| `ArrowRight` / `ArrowUp`  | Increase by `step`    |
| `ArrowLeft` / `ArrowDown` | Decrease by `step`    |
| `Home`                    | Jump to `min`         |
| `End`                     | Jump to `max`         |
| `PageUp` / `PageDown`     | Move by a larger step |
