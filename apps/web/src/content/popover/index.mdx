Unlike [`Tooltip`](/components/tooltip), a Popover:

- opens on click, not hover
- stays open until dismissed (outside click, Escape, or an explicit close)
- is fully interactive — inputs, buttons, and links inside work as usual

For a list of commands, use `Menu` instead.

## RTL

`Popover`’s `side` is **physical** — `left` / `right` do not flip when the
page direction is RTL. In an app that serves both LTR and RTL, pick the
side from the current direction:

```tsx
<PopoverPopup side={dir === 'rtl' ? 'right' : 'left'}>
```

The content inside the popup respects `dir="rtl"` on its subtree, so
`PopoverHeader`'s full-width divider, the title, and the description all
flip correctly once `dir` is set.

**Portal gotcha:** the popup is portaled to `document.body`, so it does not
inherit `dir="rtl"` from any wrapper. In a real Persian app, `<html
dir="rtl">` covers it. In this docs preview, the demo passes `dir="rtl"`
on `PopoverPopup` directly — the same exception documented for
`SheetPopup`, `DialogPopup`, `DrawerPopup`, `SelectPopup`, and
`ComboboxPopup`.
