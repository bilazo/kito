## Loading

While `loading` is `true`, the button is disabled, its label fades out, and a
spinner appears in its place. The button keeps its width and stays focusable so
keyboard users are not dropped from the tab order.

## As link

Button is framework-agnostic. To render a router link, apply the button styles
with `buttonVariants()` — no coupling to any router:

> **Do not** render a link through Base UI's `render` prop. Base UI deliberately
> forces `role="button"` on the rendered element, which tells screen readers to
> announce "button" instead of "link" and breaks native link behavior
> (Cmd/Ctrl-click, middle-click, right-click "Open in new tab"). Use
> `buttonVariants()` for links, and reserve `render` for non-link elements.

<ComponentPreview name="button/as-link" />

## RTL

Button uses logical properties (`ps-*`, `ms-*`) internally, so in an RTL
page the icon positions and text alignment flip automatically. The same
component renders correctly in both directions with no extra props.
