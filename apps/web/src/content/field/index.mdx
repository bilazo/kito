`Field` provides `role="group"` and a shared context. Inner controls that use
Base UI's `Field.Control` (our `Input` and `Textarea`) auto-wire to the label
— no manual `htmlFor`/`id` needed.

## Horizontal

For checkboxes, radios, and switches, use `orientation="horizontal"` — the
label sits beside the control.

<ComponentPreview name="field/horizontal" />

## With content

When a horizontal field has both a label and a description, wrap them in
`FieldContent`. Without it, they would each take their own row.

<ComponentPreview name="field/with-content" />

## Responsive

`orientation="responsive"` switches between column and row based on the
container width of the enclosing `FieldGroup`.

<ComponentPreview name="field/responsive" />

## RTL

`Field` uses logical properties throughout (`ms-*`, `text-start`), so the
label, description, error, and separator all flip with the page direction.
Auto-wiring between `FieldLabel` and `Field.Control` works the same in RTL.
