Sheet shares its primitive with [`Dialog`](/components/dialog) — the same
focus trapping, scroll locking, Escape-to-close, and outside-click-to-close
behaviour. Only the shell differs: Dialog is centered, Sheet is anchored.

## Sides

`side` accepts logical values:

- **`start`** — the inline-start edge (left in LTR, right in RTL)
- **`end`** — the inline-end edge (right in LTR, left in RTL) — the default
- **`top`**, **`bottom`** — physical edges, used for action sheets and
  notifications

The panel flips automatically in RTL, and the slide animation follows.

## Full-bleed content

The popup has **no padding of its own**. Padding lives on each section, so
you can insert full-bleed content — an image, a table, a divider — between
the header, body, and footer:

```tsx
<SheetPopup>
  <SheetHeader>…</SheetHeader>
  <SheetBody>
    <img src="…" className="w-full" />
    <div className="p-6">…</div>
  </SheetBody>
  <SheetFooter>…</SheetFooter>
</SheetPopup>
```

Because the popup is padding-free, the scrollbar inside `SheetBody` also
touches the panel edge rather than floating inside a padded shell.

## RTL

`Sheet` uses logical properties (`inset-inline-start`, `border-s`, `rounded-s`,
`inset-e-*`) so the panel and its border, radius, and close button flip
automatically when the page is in RTL. Only the enter/exit transforms need an
explicit override, because `translate-x` is a physical axis.

In a real Persian app, set `<html dir="rtl">` once and everything just works.
Inside the docs, the popup is portaled to `document.body`, so each example
passes `dir="rtl"` on `SheetPopup` directly to demo the effect.
