`Accordion` is a stack of `AccordionItem`s. Each item pairs an
`AccordionTrigger` with an `AccordionContent`. Base UI handles the ARIA
wiring (`aria-expanded`, `aria-controls`, `role="region"`), keyboard
navigation (Enter / Space to toggle, ArrowUp / ArrowDown to move between
triggers, Home / End to jump to the ends), and the open/close animation via
the `--accordion-panel-height` CSS variable.

Only one item is open at a time by default. Pass `multiple` to allow any
number of items to be open simultaneously.

## RTL

Every part uses logical properties (`ms-auto`, `text-start`), so the
accordion flips with the page direction. The chevron rotates 180° when an
item is open — a direction-agnostic transform, so no `rtl:` override is
needed. Accordion does not portal its content, so the preview's direction
reaches every part.
